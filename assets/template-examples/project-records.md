# 项目记录模板

以下区块分别复制到用户项目目录对应文件；不要将实际用户素材和项目记录写回技能目录。值未知时标“待确认”，未涉及字段标“不适用”。

- 候选模板编号、路径、待选/认可状态及用户选择：
