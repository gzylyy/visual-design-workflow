# D 视觉系统与可复用模板

## 无母版时的候选模板选型

先核对已有素材和用户要求。有明确母版时直接按其延展，不强制重新选型；没有母版但需求明确时，按要求制作首张母版供认可。

没有母版且用户表示“不知道”“没想好”“给我看看方向”时，设计一组可比较的候选视觉模板，默认建议三个而非固定数量。使用同一已知主题、文案和用途，分别展示构图、色彩、媒介或图文关系的区别；不靠更换主题制造差异。编号如 T01–T03，并说明各自适用情境、可调整项和保留项。

候选模板是视觉方向预览，不等于最终可编辑模板。用户只需选方向时可先做低成本预览；用户要求可复用源文件时再按下方模板合同交付。实际调用图像工具前仍确认缺失的生成要求、存放路径和格式；已授权默认值直接沿用。没有出图能力则提供明确标为方案的草图/描述，不声称已有生成图片。

将候选保存为独立探索稿，状态标为“待选择”。请用户选择编号或指出要调整的部分，等待答复后再锁定母版和扩展正式系列；用户可明确授权代选。若都不喜欢，围绕反馈修改候选，不自动批量制作所有方向。选定结果写入 project-state 和 visual-spec，保存候选 ID、母版路径及认可状态。

## 模板合同

模板由可编辑槽位、布局约束、设计变量和输出规则构成。分开保存主题数据与结构：标题/正文/日期/主视觉/来源属于内容；网格/间距/文字层级/图像裁切属于结构；色彩/字体/装饰属于主题样式。不能把科技电路、古建筑纹样或食材插画硬编码成所有主题必须出现的部分。

用设计 token 定义颜色、字体、边距、间距、标题尺度与图片比例。支持替换字段、可选字段、缺失字段时的收缩规则。使用 [poster-template.json](../assets/template-examples/poster-template.json) 配合 [poster-layout.svg](../assets/template-examples/poster-layout.svg)；JSON 是配置示例，不是自动渲染器，实际填充须使用可用排版工具。

## 文案与图像适配

标题提供正常、长文、超长三个测试输入，明确换行、字体最小值、版式变体和溢出处理。达到最小字号仍溢出时换用长文布局或提请精简，不裁掉用户文案。SVG 文字不会像浏览器段落自动换行，应使用明确行和 tspan 或实际布局引擎。

主视觉用独立图片槽，固定安全区和裁切焦点。竖图、横图、透明主体分别测试；主体超出槽位时调整裁切或布局而非拉伸。日期/来源缺失时按规则隐藏空槽，不留下虚构文案。

## 系统与交付

建立色板、字体层级、装饰组件、网格和系列母版。提供 token 名称、槽位规则、尺寸单位、字体依赖及示例。交付可编辑 SVG 或当前工具真实支持的设计格式，不把一张 JPG 叫模板源文件。

用科技、文化、美食三组内容验证可迁移性；每组验证长短标题、可选信息与不同主视觉。模板示例只是中性起点，不强制用户画风。系列任务额外读取 visual-consistency-guide。
