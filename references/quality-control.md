# 质量检查与交付门槛

每项记录“通过 / 未通过 / 未验证 / 不适用”，未查看实际输出的项目不得记为通过。先处理用户明确保留项和事实错误，再处理审美细节。

| 检查 | 判定依据 |
|---|---|
| 主题 | 主体、受众与用途对应需求 |
| 层级 | 缩略图能辨识主信息，次级信息不抢焦点 |
| 构图 | 焦点、留白、裁切、安全边距符合已确认布局 |
| 风格 | 色彩、材质、线条、光影与本项目规范匹配 |
| 融合 | 比例、透视、边缘、接触阴影无明显冲突 |
| 角色 | 脸型、头身比、服装、非对称标记逐项一致 |
| 文字 | 逐字对照、无溢出、对比清晰；无文字任务无假字 |
| 多余内容 | 没有未要求主体、标注红圈、标志或装饰 |
| 畸变 | 肢体、结构、物体连接和重复纹理无明显错误 |
| 技术 | 真实编码、尺寸、alpha、文件可打开，源文件可编辑 |
| 信息图 | 数据、单位、年代、部件关系和来源对应；不确定项标明 |
| 局部编辑 | 画布比例保留，遮罩外差异符合要求，原图保留 |
| 系列/模板 | 不变量一致，局部覆盖不污染全局，长文与跨主题测试 |
| 存放 | 路径、格式、命名和版本符合生成前约定 |

严格局部保留时，使用实际图像差分检查未修改区域；视觉对照不能证明像素相同。可编辑性需检查文本对象、图层/对象结构与字体状态，扩展名不是证据。样机或方案文件不能冒充成品。

交付时列出成果与路径、实际格式及尺寸、源文件/依赖、未解决事项。需要用户软件完成的步骤单独列明。无真实图片或没有执行工具时，只可说工作流检查通过，不可说实际出图质量通过。
