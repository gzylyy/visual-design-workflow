# E AI 图像生成与编辑

## 能力选择

先检查环境中的工具与可访问文件。区分文字生成图、图像参考、风格参考、遮罩编辑、透明输出、扩图、合成、尺寸控制与超分；只使用已证实可用的参数。工具名称不是能力证明，也不假定某家 API 或软件必然存在。

首次调用前执行 SKILL.md 的需求与存放确认：明确已知要求与未知关键项、目录、真实格式、透明背景、命名和源稿需求。用户已经提供或授权默认的内容直接复用。未确认前不进行依赖这些设置的生成。

## 参考登记

| 类型 | 控制内容 | 不自动授权 |
|---|---|---|
| 内容参考 | 物件、细节、题材、事实 | 完整复制画风/版式 |
| 风格参考 | 色彩、线条、材质、光影 | 搬入人物、文字或原构图 |
| 构图参考 | 比例、布局、主次与视角 | 复制无关主体 |
| 基础原图 | 编辑起点、保留区域 | 全图重绘或改画幅 |
| 局部参考 | 指定部件或替换属性 | 改动其他区域 |
| 标注图 | 区域、范围与位置 | 把红圈、箭头画入成品 |

多种职责可附于一张图，但要说明选用哪些属性。输入图看不到或路径失效时先处理访问，不声称已观察其内容。

## 提示与执行

按主体、动作/结构、场景、风格、构图、光影、画幅、保留项和排除项组织提示，选与任务相关字段即可。多张任务共享不变块，逐张写变量。不用堆叠形容词代替清晰设计要求。

局部编辑顺序：保存原图 → 标明 ROI/遮罩坐标与边界过渡 → 生成/编辑局部 → 匹配透视、光向、颗粒、边缘和接触阴影 → 在原图上合成 → 检查修改范围外差异。严格像素保留要求应在合成工作文件中检查遮罩外差异；JPEG 重新编码可能改变全图像素，需选择无损输出并说明。

只有整图生成工具时，不先尝试整图重绘来满足“只换一个部件且其余不变”。可生成替换部件，使用实际可用合成工具在原图中置换；若连合成也不可用，交付精确编辑方案或已生成局部素材并明确未完成整图。若用户接受近似整图版本，另存并标注差异风险，不覆盖原图。

扩图只扩展用户指定方向，不拉伸原主体；细节增强不能承诺恢复不存在的信息；无文字生成检查伪文字；透明输出检查真实 alpha 通道和浅深背景下边缘。超分与改变 DPI 标签不同，实际像素和细节分别说明。

## 存放

导出后检查文件可打开、实际编码、像素尺寸和 alpha。不要改扩展名伪装格式。实际支持何种格式就声明何种格式；需要转换时记录转换工具、损失和最终文件。记录生成工具、参考 ID、关键参数及输出版本，种子仅在工具支持且可读时记录。
