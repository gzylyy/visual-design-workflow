# B 信息可视化

## 事实与证据

建立事实表：陈述/数值、单位、时间范围、来源链接或用户资料页码、核验状态、画面位置。用户资料不是自动核验的事实；冲突和缺失单独标记。可联网时优先博物馆、研究机构、原始论文、官方统计或测绘资料；不可联网时标“未核实”，不伪造引用。

古建筑外观照可支持外形观察，不能提供隐藏梁架、内部平面或真实尺寸。没有可靠图纸时区分可见外观、依据资料复原、概念示意；避免虚构精确尺寸。年代缺来源时核查或注明“所给资料记载，待核实”；不能把概念剖面标为测绘图。

## 选择表达结构

| 关系 | 优先图式与检查 |
|---|---|
| 时间 | 时间轴；年代间距是否按比例、纪年与顺序一致 |
| 流程 | 有向节点；分支、回路及起止明确 |
| 比较 | 条形/点图；相同单位、尺度和样本口径 |
| 组成 | 分层、剖面或爆炸图；部件编号与装配关系对应 |
| 联系 | 关系图；边的方向、含义和类型有图例 |
| 科普 | 主图＋分区注释；事实和解释分开 |

比例图按数据绘制，避免图像模型随意生成轴、数字或结构关系。图表与标注尽量采用代码/矢量/排版工具，生成插画作为辅助。装饰性建筑插图不得代替实测几何。

## 图文与交付

确定主阅读路径、分区标题、图例、标注引线和来源区。颜色之外同时用标签、线型或形状编码。避免引线交叉或指向错误部件。真实尺寸与标注单位保持一致，示意图注明非按比例。

交付数据/事实表、可编辑图表和最终图；提供来源及不确定项。检查标签、加总、时间顺序、数量、结构连接和图文一一对应，不把“看起来专业”当成准确性依据。
