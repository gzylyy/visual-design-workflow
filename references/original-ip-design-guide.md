# C 原创 IP 与角色资产

## 角色设定表

先锁定角色 ID、性格和叙事角色，再落实脸型、五官间距、发型发色、身高比例、体态、服装结构、配饰、鞋与识别标记。记录色板、线条、材质与光影。用户已有明确设定则直接整理，不重复询问。

左右始终按角色自身方位记录，不按观看者左右。左脸雀斑、右手义肢等非对称特征在背面和侧面逐项检查，不能镜像后假称一致。示例三视图可隐藏不可见标记，但不能把它换到可见的另一侧。

## 母版到三视图

1. 整理或生成一张可辨认、无遮挡的角色母版，记录固定特征与允许变化。
2. 正、侧、背视图使用一致的头身比、画幅、地面基线和相机高度；默认正交/弱透视中性站姿，用户指定透视时遵从并说明比较限制。
3. 统一肩、腰、髋、膝位置；背面补充合理衣物接缝与配饰连接，未知细节标为设计决定而不是参考中已存在的事实。
4. 用参考控制和局部修正延展，不把三个独立随机结果直接拼成三视图。缺相应工具时给出设定与待完成视图，不保证仅凭文字实现严格一致。
5. 逐视角核对五官、发型轮廓、配件数量、非对称标记、服装色块、比例与画风。

## 表情、动作和场景

表情改变表情肌与眼眉，维持基础脸型和识别特征。动作改变姿态与布料受力，不任意新增服装件。场景改变环境光，仍需保留材质固有色和角色身份；严重遮挡时另保留可检查的参考。

多角色共享渲染规则、比例逻辑、线条与光影；身份特征保持独立。角色资产库按 ID/版本/视图/表情/动作记录，附母版路径和可见特征核对表。交付设定表、母版、实际生成视图及缺失清单，不将未生成的视图列为成品。
